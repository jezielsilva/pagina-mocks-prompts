ETAPA B — ESTRUTURA DO CARD (template)
Cada card tem 3 partes, nessa ordem, dentro de .grid-item (que já usa .file-list-item do UI-Kit):

<div class="file-list-item grid-item" [class.active]="selecionado" tabindex="0" role="gridcell">
  // 1) Cabeçalho: ícone do tipo + nome + ⋮
  <div class="grid-item-head">
    <e-icon [icon]="iconeDoTipo" size="16"></e-icon>
    <span class="grid-item-name" [title]="nomeTruncado ? item.nome : null">
      @if (item.favorito) { <span class="text-secondary">★ </span> }
      {{ nomeSemExtensao }}
    </span>
    // usar o MESMO botão de ação do modo lista (ícone, sem borda)
    <button type="button" class="btn btn-icon btn-sm grid-item-menu" aria-label="Ações"><e-icon icon="more-vertical" size="16"></e-icon></button>
  </div>

  // 2) Miniatura
  <div class="grid-item-thumb" [class.is-folder]="item.tipo === 'pasta'">
    @if (item.tipo === 'pasta') {
      <e-icon icon="folder" size="64" class="text-primary"></e-icon>
    } @else if (item.miniaturaUrl) {
      <img class="grid-item-paper" [src]="item.miniaturaUrl" alt="" loading="lazy">
    } @else {
      // fallback: "folha" branca com o ícone do tipo no centro
      <div class="grid-item-paper is-fallback"><e-icon [icon]="iconeDoTipo" size="32"></e-icon></div>
    }
    @if (item.prazo) { <span class="grid-item-flag"><e-badge class="badge-sm" ...>{{ prazoCurto }}</e-badge></span> }
  </div>

  // 3) Rodapé
  <div class="grid-item-foot">
    <div class="badge-list"> (badges de classificação já existentes, em modo .badge-sm) </div>
    @if (item.tipo === 'pasta') {
      <span class="grid-item-info">{{ qtdPastas }} pastas · {{ qtdArquivos }} arquivos</span>
    } @else {
      <span class="grid-item-info">{{ item.autorNome }} · {{ item.dataAlteracao | date:'dd/MM/yyyy' }} · {{ item.tamanhoFormatado }}</span>
    }
  </div>
</div>

Observações:
- Use os campos que JÁ existem no DTO do item (autor, data de alteração, tamanho, contagem de filhos). Se a contagem de filhos da pasta não vier do back, mostre só "Pasta" e informe na entrega (não calcule no front).
- O tamanho formatado (KB/MB) deve usar o pipe/helper que o modo lista já usa. Não crie outro.
- miniaturaUrl = a URL de miniatura do prompt de miniaturas. Se ainda não existir, use só o fallback.
