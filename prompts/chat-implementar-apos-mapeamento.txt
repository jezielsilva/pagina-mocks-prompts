    e) retorna { conversa, mensagem }.
  - Usar sessão/transação do Mongo para conversa + mensagem se o projeto já usa sessão em outros caminhos. Se não, a ordem acima + índices garantem consistência (falha entre c e d deixa conversa sem mensagem que será REAPROVEITADA na próxima tentativa via b).
