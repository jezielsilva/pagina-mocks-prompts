[Área: Frontend (SCSS do grid) | Skills: UI-Kit]

TAREFA
Duas correções no MODO GRID do módulo Documentos. Só SCSS (e o wrapper, se precisar). NÃO crie testes. Não mexa no card, que já está aprovado.

PROBLEMA 1 — o cartão do grid não ocupa a altura disponível
Embaixo do cartão branco que envolve os cards sobra uma faixa cinza vazia (~150px) até o fim da tela. O cartão deve ESTICAR até o fim da área visível da página, menos um respiro de 16px embaixo.

PROBLEMA 2 — falta a barra de rolagem vertical
O grid rola, mas a barra de rolagem não aparece à direita. Ela deve ficar visível, fina, no padrão do sistema (a mesma usada nas outras listas / colunas do modo lista).

ETAPA A — INVESTIGAR (uma linha por item)
A1. Cadeia de altura: do :host da página até o .file-grid (.document-content.document-grid-view > .file-grid-card > .card-body > .file-grid). Para cada um: display, height, max-height, flex. Quem tem altura FIXA ou max-height (ex.: calc(100vh - Npx), height em px) que não usa o espaço todo?
A2. A barra sumiu por quê? Procure no SCSS do grid e nos globais: scrollbar-width: none, ::-webkit-scrollbar { display: none / width: 0 }, overflow: hidden no .file-grid, ou uma classe utilitária (ex.: .no-scrollbar / .hide-scrollbar) aplicada no template.
A3. Qual é a classe/mixin de scrollbar padrão do sistema (UI-Kit)? Arquivo e nome.

ETAPA B — CORRIGIR

1) Altura: cadeia flex de cima até o grid, sem altura mágica
// página/área de conteúdo do módulo (o pai que já ocupa a altura da tela)
.document-content.document-grid-view {
  display: flex;
  flex-direction: column;
  flex: 1 1 auto;
  min-height: 0;
  height: 100%;          // ou, se o pai não tiver altura definida: height: calc(100dvh - <altura real do header + toolbar + filtros>)
  padding-bottom: 16px;  // respiro final
}
.file-grid-card {
  display: flex;
  flex-direction: column;
  flex: 1 1 auto;        // ESTICA até o fim
  min-height: 0;
  max-height: none;      // remover max-height antigo
}
.file-grid-card > .card-body {
  display: flex;
  flex-direction: column;
  flex: 1 1 auto;
  min-height: 0;
  overflow: hidden;
}
.file-grid {
  flex: 1 1 auto;
  min-height: 0;
  overflow-y: auto;      // quem rola é o grid
  overflow-x: hidden;
}
Regras:
- Remova height/max-height fixos em px ou calc que limitam o cartão (os que você achou em A1).
- Prefira a cadeia flex com min-height: 0. Só use calc(100dvh - X) se nenhum pai tiver altura definida. Nesse caso, X = soma REAL medida no DevTools (header + abas + filtros + gaps), e informe o valor.
- Não mexa no grid-auto-rows: max-content nem no min-height do card (já corrigidos).

2) Scrollbar visível
- Remova o que esconde a barra no .file-grid (achado em A2).
- Aplique a classe/mixin padrão do sistema (A3) no .file-grid.
- Se NÃO existir padrão, use este, só com tokens:
.file-grid {
  scrollbar-width: thin;
  scrollbar-color: var(--color-slate-300) transparent;
  scrollbar-gutter: stable;          // reserva o espaço, não "pula" o layout quando a barra aparece
}
.file-grid::-webkit-scrollbar { width: 8px; }
.file-grid::-webkit-scrollbar-track { background: transparent; }
.file-grid::-webkit-scrollbar-thumb {
  background: var(--color-slate-300);
  border-radius: 999px;
  border: 2px solid transparent;
  background-clip: padding-box;
}
.file-grid::-webkit-scrollbar-thumb:hover { background: var(--color-slate-400); background-clip: padding-box; }
Confirme que os tokens têm valor nos modos claro E escuro. Se não tiverem, crie tokens de scrollbar no tema com os dois modos.
