[Área: Frontend (SCSS + template da sidebar) | Skills: UI-Kit]

TAREFA
Corrigir a sidebar do módulo Documentos e remover scrolls internos desnecessários. Veja o mock atualizado no portal ("Mock — Documentos"): ele já tem o comportamento correto. NÃO crie testes. Só front.

PROBLEMAS
1. Ao abrir "Todos os documentos", a lista empurra o card "Amplie o seu armazenamento / Fazer upgrade" para fora da tela.
2. Há scrolls demais: um dentro do acordeão, outro na sidebar, scroll duplo no conteúdo etc.

REGRA: NO MÁXIMO UM SCROLL VERTICAL POR COLUNA
- Coluna do conteúdo: rola SÓ a área dos arquivos (grid ou lista). No modo lista (Finder), cada coluna do Finder rola sozinha, mas a área em volta NÃO rola.
- Sidebar: rola SÓ a parte de cima (Novo arquivo + atalhos + armazenamento + Todos os documentos + Classificações), como UM bloco. O card de upgrade fica FORA desse scroll, fixo na base visível da sidebar.
- A página não rola.

ETAPA A — INVESTIGAR (uma linha por item)
A1. Liste TODOS os elementos do módulo com overflow-y auto/scroll (grep no SCSS do módulo e no template por overflow, overflow-y, cdk-virtual-scroll, perfect-scrollbar). Diga quais rolam de fato com o acordeão aberto.
A2. Estrutura atual da sidebar (ordem dos filhos) e qual elemento tem overflow.

ETAPA B — SIDEBAR (template)
Envolver tudo, MENOS o card de upgrade, num wrapper rolável:
<aside class="documentos-sidebar">
  <div class="sidebar-scroll">
    (Novo arquivo)
    (Favoritos / Lixeira)
    (Armazenamento)
    (Acordeão Todos os documentos)
    (Classificações, se existir)
  </div>
  (Card Amplie o seu armazenamento / Fazer upgrade)   // fora do scroll
</aside>

ETAPA C — SCSS
.documentos-sidebar {
  display: flex;
  flex-direction: column;
  gap: 10px;
  min-height: 0;
  overflow: hidden;          // a sidebar em si NÃO rola
}
.sidebar-scroll {
  flex: 1 1 auto;
  min-height: 0;
  overflow-y: auto;          // ÚNICO scroll da sidebar
  display: flex;
  flex-direction: column;
  gap: 10px;
  margin: 0 -6px;            // a barra não cola no conteúdo
  padding: 0 6px;
  scrollbar-width: thin;
  scrollbar-color: <token borda forte> transparent;
}
.sidebar-scroll > * { flex-shrink: 0; }        // nada dentro encolhe/esmaga
.<card-upgrade> { flex-shrink: 0; margin-top: auto; }   // fixo na base

Acordeão "Todos os documentos": REMOVER o scroll interno.
- Aberto: o conteúdo cresce na altura natural (overflow visible, sem max-height, sem overflow-y). Quem rola é o .sidebar-scroll.
- Mantenha a animação de abrir/fechar (grid-template-rows 0fr → 1fr). Durante a animação, o filho usa overflow hidden. Depois de aberto, overflow visible.
- Remova flex 1, min-height e max-height antigos do acordeão.

ETAPA D — CONTEÚDO (remover scroll duplo)
- O cartão da área de arquivos: display flex, flex-direction column, min-height 0, overflow hidden.
- Modo grid: o .file-grid é o ÚNICO que rola (overflow-y auto). Os wrappers acima dele usam overflow hidden.
- Modo lista: o contêiner .finder ocupa height 100% e min-height 0 (REMOVER qualquer min-height fixo, ex.: 480px, que gera scroll externo). Rolam só as colunas internas do Finder e o painel de preview.
- Remova scrollbar-gutter: stable, se tiver sido adicionado.

CRITÉRIOS DE ACEITE (1366×620, 1366×768 e 1920×1080)
1. Com "Todos os documentos" aberto, o card de upgrade fica sempre visível, colado na base da sidebar.
2. A sidebar tem só uma barra de rolagem, e só quando o conteúdo de cima não cabe.
3. O acordeão não tem barra própria.
4. Grid: só uma barra (a do grid). Lista: só as das colunas do Finder.
5. A página não rola.
6. Sem hex, sem !important, sem style inline.
