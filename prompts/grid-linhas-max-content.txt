[Área: Frontend (SCSS do grid) | Skills: UI-Kit]

TAREFA
Corrigir de vez os cards esmagados no MODO GRID. A causa foi encontrada na sua investigação anterior. A correção é de 2 linhas de SCSS mais garantir que o navegador carregue o CSS novo. NÃO crie testes. Não mexa em template, lógica ou back.

CAUSA (com base nos números que você mediu)
- O .file-grid tem altura DEFINIDA (528,7px, porque é flex: 1 1 auto dentro do card) e rola (overflow auto). Isso está certo.
- O .grid-item tem overflow: hidden. Pela especificação do CSS Grid, um item com overflow diferente de visible tem tamanho MÍNIMO automático = 0.
- Com linhas "auto", o navegador começa cada linha no tamanho mínimo (0) e só cresce até caber no espaço livre do contêiner. Como o contêiner tem altura fixa, ele divide 528px entre as linhas: 5 linhas viram 86,8px. Com 40 itens, as linhas ficam ainda menores.
- Por isso a miniatura mediu 16px: o card de 86,8px a espremeu. NÃO é bundle antigo. align-content: start não resolve, porque o problema está no tamanho das linhas, não na sobra.

CORREÇÃO (copiar exatamente em documentos-grid.component.scss)

.file-grid {
  // linha com a altura TOTAL do conteúdo do card, nunca espremida pelo espaço disponível
  grid-auto-rows: max-content;
  align-content: start;
}

.grid-item {
  // segunda trava: o card nunca fica menor que o próprio conteúdo
  min-height: max-content;
}

Mantenha o resto que já existe:
- .file-grid com flex: 1 1 auto, min-height: 0 e overflow-y: auto (quem rola é o próprio grid, dentro do cartão);
- .grid-item-thumb com flex: 0 0 168px e height: 168px (132px no celular);
- .grid-item-head e .grid-item-foot com flex-shrink: 0.
Não use !important.

GARANTIR QUE O CSS NOVO CARREGOU (o motivo de você ter achado que era bundle antigo)
1. Pare o ng serve e rode de novo.
2. No navegador, com o DevTools aberto: aba Network, marque "Disable cache" e dê Ctrl+Shift+R.
3. Confirme no DevTools, em .file-grid > Styles, que a regra grid-auto-rows: max-content aparece vindo do documentos-grid.component.scss. Se não aparecer, o componente está usando outro arquivo de estilo: verifique o styleUrl(s) do @Component e se existe outro SCSS com .file-grid sobrescrevendo (busque ".file-grid" no projeto inteiro e informe todos os arquivos).

CRITÉRIOS DE ACEITE
1. Em Computed, .grid-item mede cerca de 300px de altura (cabeçalho + 168px de miniatura + rodapé), e .grid-item-thumb mede 168px.
2. Com 20, 40 e 69 itens, o card tem a mesma altura. Só aumenta o número de linhas, e o grid rola dentro do cartão.
3. O "Carregar mais" continua centralizado no fim.
4. O modo lista não muda.
