[Área: Frontend (SCSS do grid) | Skills: UI-Kit]

TAREFA
Corrigir os cards do MODO GRID que estão ESMAGADOS na altura. Só SCSS e, se necessário, a estrutura do contêiner. Não mude template do card, regra de negócio ou back. NÃO crie testes.

O QUE ACONTECE (prints, área Tarefas)
1. Com 20 itens: cada card tem uns 140px de altura. A miniatura aparece cortada, só a faixa de baixo com a etiqueta "TXT"/"PNG". O rodapé (badges + autor · data · tamanho) NÃO aparece.
2. Depois de "Carregar mais" (40 itens): os cards ficam AINDA MENORES (~80px). Sobra só a linha do nome com o ⋮, e a miniatura some.
3. Conclusão: a altura TOTAL do grid está fixa e é dividida entre as linhas. Quanto mais linhas, menor cada card. O correto é cada card ter a altura do PRÓPRIO conteúdo (~310px) e a área ROLAR quando não couber.

COMO DEVE FICAR (igual ao mock)
- Card com altura natural: cabeçalho (~44px) + miniatura (168px fixos) + rodapé (badges + linha de info, ~70px). Todos os cards da mesma linha têm a mesma altura.
- Com 20, 40 ou 69 itens, o card tem SEMPRE a mesma altura. Só aumenta o número de linhas.
- A área de conteúdo rola verticalmente (scroll). O "Carregar mais" fica no fim, depois da última linha, centralizado (isso já está certo, não mexa).

ETAPA A — INVESTIGAR (responda antes de mudar, uma linha por item)
No DevTools, selecione o .file-grid (contêiner do grid) e depois um .grid-item:
A1. .file-grid → Computed: display, height, max-height, overflow, grid-template-rows, grid-auto-rows, align-content, align-items. Diga de qual seletor vem cada valor que NÃO for o padrão.
A2. Pais do .file-grid até o card branco da página: algum tem height fixa / height: 100% / flex: 1 com overflow: hidden? Qual deles deveria rolar (overflow-y: auto)?
A3. .grid-item → Computed: height, max-height, min-height, flex-shrink, overflow. Algum height: 100% ou max-height?
A4. .grid-item-thumb → Computed: height e flex-shrink. Está encolhendo (flex-shrink 1 com height 168px)?
A5. Procure no SCSS e no template: grid-auto-rows, grid-template-rows, "1fr" em linhas, height: 100% no grid ou no card, flex-wrap usado como grid, display: flex em .file-grid.

ETAPA B — CORRIGIR (copiar exatamente)

// 1) Grid: linhas com altura do conteúdo, nunca divididas pelo espaço disponível
.file-grid {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(224px, 1fr));
  grid-auto-rows: auto;        // NÃO usar 1fr / minmax(0, 1fr)
  grid-template-rows: none;    // remover qualquer template de linhas
  align-content: start;        // linhas grudam no topo, não esticam nem espremem
  align-items: stretch;        // cards da mesma linha com a mesma altura
  gap: 16px;
  padding: 16px;
  height: auto;                // remover height fixa / 100%
  max-height: none;
  overflow: visible;           // quem rola é o pai (passo 2)
}

// 2) O pai que ocupa o espaço da página é quem ROLA
// (o elemento que você achou em A2; exemplo de nome: .documentos-conteudo / .view-body)
.<pai-do-grid> {
  flex: 1 1 auto;
  min-height: 0;
  overflow-y: auto;
}
// Se a página inteira já rola (sem altura fixa no pai), não precisa do passo 2: só remova height/overflow fixos.

// 3) Card: nunca encolhe
.grid-item {
  display: flex;
  flex-direction: column;
  height: auto;
  min-height: 0;
  max-height: none;
  flex-shrink: 0;
  overflow: hidden;
}

// 4) Miniatura: altura fixa, não encolhe
.grid-item-thumb {
  flex: 0 0 168px;
  height: 168px;
}

// 5) Cabeçalho e rodapé: não encolhem
.grid-item-head,
.grid-item-foot { flex-shrink: 0; }

Remova da base qualquer regra que conflite com isso (height: 100% no card, grid-auto-rows: 1fr, max-height no grid, overflow: hidden no grid). Não use !important: se precisar, ajuste a especificidade ou apague a regra antiga.

Celular (<= 576px): mantém tudo e só muda a miniatura:
.grid-item-thumb { flex-basis: 132px; height: 132px; }

CRITÉRIOS DE ACEITE
1. Com 20 itens: todo card mostra o cabeçalho, a miniatura inteira de 168px e o rodapé com badges + "autor · data · tamanho".
2. Depois de "Carregar mais" (40 e 69 itens): os cards têm EXATAMENTE a mesma altura de antes. Só aparecem mais linhas.
3. A área rola verticalmente e o "Carregar mais" fica no fim, centralizado.
4. Cards da mesma linha têm a mesma altura.
5. O modo lista não muda.
6. Sem hex, sem !important, sem style inline.
